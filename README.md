# 🌐 Nova Web Agency - Portafolio Personal

Sitio web de portafolio profesional desarrollado para exhibir proyectos de desarrollo de software, aplicaciones web y stack tecnológico.

🔗 **Enlace en producción:** https://linktr.ee/NovaWebAgency

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Tailwind CSS.
- **Despliegue:** Vercel (CI/CD continuo).
- **Control de versiones:** Git y GitHub.
- **Gestor de paquetes:** npm.

## ⚙️ Instrucciones para ejecutar el proyecto en la computadora local

### 1. Clonar este repositorio

Abre una terminal y ejecuta el siguiente comando:

```bash
git clone https://github.com/albertoposada500-coder/nexus-dev-studio.git
```

### 2. Ingresar a la carpeta del proyecto

```bash
cd nexus-dev-studio
```

### 3. Instalar las dependencias

```bash
npm install
```

### 4. Ejecutar el proyecto

```bash
npm run dev
```

### 5. Abrir el sitio web

Después de ejecutar el comando anterior, la terminal mostrará una dirección local. Ábrela en tu navegador para visualizar el portafolio.
